Grouping by Several Keys

Overview

Two keys give a row per combination, and an index with two levels.

Intermediate 20–25 min
← Previous Next: transform versus aggregate

What You Will Learn in This Lesson

By the end of this lesson, you will be able to:

  • Group by more than one column.
  • Read a two-level index.
  • Flatten the result back into a plain table.
  • Say what happens to combinations that never occur.

Why This Matters

"Per subject per year" is one group-by, not two. The result carries an index with two levels, which is the first genuinely unfamiliar object in pandas — and knowing how to flatten it is most of what you need.

Step 1: A list of columns

Pass a list and you get a row per combination that actually occurs in the data.

1

One row per combination

The index now has two levels, printed as two columns down the left.

import pandas as pd

df = pd.DataFrame({"subject": ["m", "m", "a"], "year": [10, 11, 10], "score": [90, 80, 70]})
out = df.groupby(["subject", "year"])["score"].mean()
print(out)
print(out.index.nlevels)
2

Reaching into it

A tuple indexes both levels at once; naming just the first gives you everything under it.

import pandas as pd

df = pd.DataFrame({"subject": ["m", "m", "a"], "year": [10, 11, 10], "score": [90, 80, 70]})
out = df.groupby(["subject", "year"])["score"].mean()
print(out[("m", 10)])
print(out["m"])

Step 2: Flattening the result

Most of the time you want a plain table with the keys as ordinary columns, which is one call away.

1

reset_index

Both levels become columns and the index goes back to 0, 1, 2. This is the form you would write to a file or hand to a chart.

import pandas as pd

df = pd.DataFrame({"subject": ["m", "m", "a"], "year": [10, 11, 10], "score": [90, 80, 70]})
flat = df.groupby(["subject", "year"])["score"].mean().reset_index()
print(flat)
print(list(flat.columns))
2

Combinations that never happened

A pair with no rows does not appear — the result has one row per combination that exists, not per combination that is possible. If the missing ones matter, unstack lays the grid out and shows them as NaN.

import pandas as pd

df = pd.DataFrame({"subject": ["m", "a"], "year": [10, 11], "score": [90, 70]})
out = df.groupby(["subject", "year"])["score"].mean()
print(len(out), "rows for", df["subject"].nunique() * df["year"].nunique(), "possible pairs")
print(out.unstack())

Step 3: When to Use It

Combinations of categories

Team and term, region and month: one row per pair that exists.

df.groupby(["team", "term"])["score"].mean()

Drilling down

A two-level index lets you select one outer group and see its inner breakdown.

When Not to Use It

Do not forget reset_index when the next step expects ordinary columns. And remember combinations with no rows do not appear at all.
