Unit 7 • Lesson 6

Pivot Tables

Overview

A grouped summary laid out as a grid.

Intermediate 20–25 min
← Previous Unit 7 test

What You Will Learn in This Lesson

By the end of this lesson, you will be able to:

  • Lay a two-key summary out as a grid.
  • Name what goes down, what goes across, and what fills the cells.
  • Say what aggfunc defaults to.
  • Read the gaps in the grid.

Why This Matters

A pivot table is the same computation as a two-key group-by, arranged so a person can read it. That arrangement is the whole value: a grid with subjects down and years across is scannable in a way a 40-row two-level index is not.

Step 1: Rows, columns and a value

index is what goes down the side, columns is what goes across the top, values is what fills the cells.

1

The same numbers, laid out

Compare it with the group-by beneath. Identical arithmetic, different shape.

import pandas as pd

df = pd.DataFrame({"subject": ["m", "m", "a"], "year": [10, 11, 10], "score": [90, 80, 70]})

print(pd.pivot_table(df, index="subject", columns="year", values="score", aggfunc="mean"))
print()
print(df.groupby(["subject", "year"])["score"].mean())
2

aggfunc is not count

It defaults to mean, which surprises people expecting a spreadsheet pivot's count. Name it whenever you mean something else.

import pandas as pd

df = pd.DataFrame({"subject": ["m", "m"], "year": [10, 10], "score": [90, 80]})
print(pd.pivot_table(df, index="subject", columns="year", values="score"))
print(pd.pivot_table(df, index="subject", columns="year", values="score", aggfunc="size"))

Step 2: Combinations with no rows

A grid has a cell for every combination, including the ones the data never had. Those cells are NaN, and that is information.

1

The gaps

Unlike a group-by, which simply omits an absent pair, the grid shows it as an empty cell — which is often exactly what you wanted to see.

import pandas as pd

df = pd.DataFrame({"subject": ["m", "a"], "year": [10, 11], "score": [90, 70]})
print(pd.pivot_table(df, index="subject", columns="year", values="score", aggfunc="mean"))
2

Filling them, if a zero is honest

fill_value replaces the gaps. Use it only when "no rows" really does mean zero — for a count it usually does, for a mean it never does.

import pandas as pd

df = pd.DataFrame({"subject": ["m", "a"], "year": [10, 11], "score": [90, 70]})
print(pd.pivot_table(df, index="subject", columns="year", values="score",
                     aggfunc="size", fill_value=0))

Filling a missing mean with 0 claims a group scored nothing, when the truth is that nobody sat it. The gap was the honest answer.

Step 3: When to Use It

A grid people will read

One key down the side, one across the top, a summary in each cell.

pd.pivot_table(df, index="team", columns="term", values="score", aggfunc="mean")

Totals along the edges

margins=True adds row and column totals to the grid.

When Not to Use It

Do not leave aggfunc to its default without thinking. Duplicate combinations are averaged, which may not be what the cell should say.
