Unit 7 • Lesson 2

Counting Groups

Overview

How many of each, and the difference between size and count.

Intermediate 20–25 min
← Previous Next: agg with Several Summaries

What You Will Learn in This Lesson

By the end of this lesson, you will be able to:

  • Count the distinct values in a column with value_counts.
  • Say the difference between size and count.
  • Turn counts into proportions.
  • Choose which one answers the question you were asked.

Why This Matters

"How many of each" is the most common question anyone asks of a table, and there are two right answers to it depending on whether you mean rows or values. On a column with gaps in it the two differ, and picking the wrong one gives a number that is plausible and wrong.

Step 1: value_counts for one column

For a single column this is the shortest path: distinct values and how often each appears, already sorted by frequency.

1

Counts, and shares

normalize=True turns the counts into proportions of the whole, which is usually what a reader wants beside them.

import pandas as pd

city = pd.Series(["L", "Y", "L", "L"])
print(city.value_counts())
print(city.value_counts(normalize=True))
2

Missing values are not counted by default

So the counts can sum to less than the length of the column. dropna=False makes the gaps a category of their own.

import pandas as pd
import numpy as np

city = pd.Series(["L", np.nan, "Y"])
print(city.value_counts().sum(), "of", len(city))
print(city.value_counts(dropna=False))

Step 2: size counts rows, count counts values

On a group, size is how many rows are in it. count is how many non-missing values a column has in it. They differ exactly where the data has holes.

1

The difference, shown

Ten rows with three missing scores give a size of 10 and a count of 7. Which one you want depends on whether you are asking "how many students" or "how many marked papers".

import pandas as pd
import numpy as np

df = pd.DataFrame({"k": ["a", "a", "a"], "v": [1, np.nan, 3]})
g = df.groupby("k")
print("size:", g.size().to_dict())
print("count:", g["v"].count().to_dict())
2

Both at once

Asking for both is usually the honest answer, because the gap between them is itself information about the data.

import pandas as pd
import numpy as np

df = pd.DataFrame({"k": ["a", "a", "b"], "v": [1, np.nan, 3]})
print(df.groupby("k")["v"].agg(["size", "count", "mean"]))

Note the mean: it is computed over the count, not the size. A group of three rows with one missing value has its mean taken over two.

Step 3: When to Use It

Rows per group

size counts every row, including those with missing values.

df.groupby("team").size()

Values per group

count counts the non-missing values in a column — how many actually have a score.

When Not to Use It

Do not use size and count interchangeably. When a column has gaps they give different answers, and the difference is the number of missing values.
