A Summary Table

Overview

The small table that goes under the chart.

Intermediate 20–25 min
← Previous Next: Writing Up a Finding

What You Will Learn in This Lesson

By the end of this lesson, you will be able to:

  • Build a table with one row per thing and one column per fact.
  • Order it by the thing being compared.
  • Include the group size.
  • Say what the table does that the chart cannot.

Why This Matters

A chart shows the shape; the table pins the values. Together they answer both "what is the pattern" and "what exactly was the number", and the group size in the table is what stops a reader over-reading a bar built from two rows.

Step 1: One row per thing, one column per fact

The table under a chart is small on purpose: the few numbers the picture cannot state exactly, and the counts behind them.

1

Count and mean together

One group-by gives both. The count is not optional — it is what makes the mean interpretable.

import pandas as pd

df = pd.DataFrame({"team": ["a", "a", "b"], "score": [90.0, 80.0, 95.0]})
print(df.groupby("team")["score"].agg(["count", "mean"]).round(1))
2

Name the columns for a reader

"count" and "mean" are how it was computed. "students" and "mean score" are what it means.

import pandas as pd

df = pd.DataFrame({"team": ["a", "a", "b"], "score": [90.0, 80.0, 95.0]})
out = df.groupby("team").agg(
    students=("score", "count"),
    mean_score=("score", "mean"),
).round(1)
print(out)

Step 2: Order it by the thing being compared

The first row should be the one the reader is looking for. Alphabetical order almost never is.

1

Sort by the value

Best first, so the ranking is visible without reading every row.

import pandas as pd

df = pd.DataFrame({"team": ["a", "a", "b"], "score": [90.0, 80.0, 95.0]})
out = df.groupby("team")["score"].agg(["count", "mean"]).round(1)
print(out.sort_values("mean", ascending=False))
2

And match the chart

If the bars are ordered by value, the table should be too. A reader moving between the two should not have to re-find each row.

import pandas as pd

df = pd.DataFrame({"team": ["zeta", "alpha", "mu"], "score": [70.0, 90.0, 80.0]})
order = df.groupby("team")["score"].mean().sort_values(ascending=False).index
print(list(order))

Step 3: When to Use It

Under a chart

The exact values the picture only shows approximately, with the group sizes.

df.groupby("team").agg(students=("score", "count"), mean_score=("score", "mean"))

When readers need to look things up

A short, sorted table answers “what exactly was it for my group”.

When Not to Use It

Do not paste the whole grouped output. A summary table that needs scrolling is data, not a summary — keep the few columns the question needs.
