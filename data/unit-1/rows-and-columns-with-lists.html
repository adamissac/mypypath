Rows and Columns with Lists

Overview

A table is a list of lists, and a column is what you pull out of it.

Beginner 20–25 min
← Previous Next: Records as Dictionaries

What You Will Learn in This Lesson

By the end of this lesson, you will be able to:

  • Store a small table as a list of row lists.
  • Read one row, one cell, and one column out of it.
  • Build a column with a comprehension over the rows.
  • Explain the weakness of position-based rows that the next lesson fixes.

Why This Matters

Every table you will ever analyse — a CSV, a spreadsheet, a DataFrame — is rows and columns. Building one out of plain lists first shows exactly what a table is underneath, so when pandas hands you df["score"] you know it is doing the comprehension in this lesson for you, and why it needed column names to do it.

Step 1: A table is a list of rows

The simplest possible table: an outer list, holding one inner list per row, each inner list holding the values in a fixed order.

1

One index for a row, two for a cell

The first index picks the row. The second picks a position inside that row. Row first, then column — the same order a spreadsheet uses.

table = [
    ["Ada", 92, "maths"],
    ["Grace", 88, "computing"],
    ["Alan", 79, "maths"],
]

print(table[0])      # the first row
print(table[0][1])   # the second cell of the first row
print(table[2][2])   # the third cell of the third row
2

The shape of the table

len(table) is the number of rows. len(table[0]) is the number of columns, assuming every row has the same length — an assumption real files break more often than you would hope.

table = [["Ada", 92, "maths"], ["Grace", 88, "computing"]]

print("rows:", len(table))
print("columns:", len(table[0]))

Step 2: A column is a comprehension

There is no column object in a list of lists. To work on one, you build a new list out of the same position in every row.

1

Pulling one position out of every row

[row[1] for row in table] reads as “the second value of each row”. That is what a column is.

table = [["Ada", 92], ["Grace", 88], ["Alan", 79]]

scores = [row[1] for row in table]
names = [row[0] for row in table]
print(names)
print(scores)
2

Summarise the column, not the table

Once the column is a list of numbers, every summary from the last lesson works on it.

table = [["Ada", 92], ["Grace", 88], ["Alan", 79]]

scores = [row[1] for row in table]
print(sum(scores) / len(scores))
3

A column with a condition

Adding an if keeps only some rows while taking the column — the names of everyone who studies maths, say.

table = [["Ada", 92, "maths"], ["Grace", 88, "computing"], ["Alan", 79, "maths"]]

maths = [row[0] for row in table if row[2] == "maths"]
print(maths)

Step 3: The weakness: positions mean nothing

This representation works, and it has one serious problem.

1

row[1] does not say what it is

You have to remember that position 1 is the score. Six months later, or for someone else reading the code, row[1] is a mystery.

row = ["Ada", 92, "maths"]
print(row[1])   # the score -- but only if you remember
2

A new column moves everything

Insert an age column after the name and every row[1] now reads the age. Nothing raises; the average is just the average age. The next lesson fixes this by giving every value a name.

table = [["Ada", 36, 92], ["Grace", 45, 88]]

# Written before the age column existed. Still runs. Now wrong.
scores = [row[1] for row in table]
print(sum(scores) / len(scores))
