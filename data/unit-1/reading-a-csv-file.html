Reading a CSV File

Overview

The csv module turns a file of text into rows you can work with.

Beginner 20–25 min
← Previous Next: Summarising Numbers

What You Will Learn in This Lesson

By the end of this lesson, you will be able to:

  • Say why splitting each line on commas breaks on real files.
  • Read a file with csv.reader inside a with block.
  • Read named records with csv.DictReader.
  • Remember that every value read from a file is a string.

Why This Matters

Almost all data you analyse arrives as a file, and CSV is the most common format there is. Reading it correctly is the “get the data” step for real — and the two traps in it, quoted commas and everything-is-text, are the same two traps pandas.read_csv handles for you in unit 5. Seeing them by hand first is what makes its options make sense.

Step 1: Why not just split on commas

A CSV file looks like lines of values separated by commas, so line.split(",") looks like it should work. It works until the first real file.

1

A comma inside a value

A name like "Lovelace, Ada" is one field. CSV protects it with quotes; split does not know about quotes and cuts the row in the wrong place, shifting every column after it.

line = '"Lovelace, Ada",92'

print(line.split(","))   # three pieces -- wrong
2

The csv module knows the rules

csv.reader understands quoting, escaped quotes and the line endings different systems write. Here it reads from an in-memory string, so the example runs without a file; on a real file the loop is identical.

import csv
import io

text = 'name,score\n"Lovelace, Ada",92\nGrace,88\n'
for row in csv.reader(io.StringIO(text)):
    print(row)

Step 2: Opening the file properly

A file has to be opened and closed. The with statement does both, including when something goes wrong halfway through.

1

with open(...) as f

The block reads the file; leaving the block closes it. The example writes a small file first so there is something to read.

import csv

with open("scores.csv", "w") as f:
    f.write("name,score\nAda,92\nGrace,88\n")

with open("scores.csv") as f:
    for row in csv.reader(f):
        print(row)
2

The header is just the first row

csv.reader does not treat the header specially. next(reader) takes it off the front, so the loop sees only data.

import csv

with open("scores.csv", "w") as f:
    f.write("name,score\nAda,92\nGrace,88\n")

with open("scores.csv") as f:
    reader = csv.reader(f)
    header = next(reader)
    print("columns:", header)
    for row in reader:
        print(row)

Step 3: DictReader gives you named rows

The last lesson argued for records keyed by column name. csv.DictReader builds exactly those, using the header line for the keys.

1

One dictionary per row

No next, no zip: the header becomes the keys automatically, and row["score"] works straight away.

import csv

with open("scores.csv", "w") as f:
    f.write("name,score\nAda,92\nGrace,88\n")

with open("scores.csv") as f:
    for row in csv.DictReader(f):
        print(row["name"], row["score"])
2

Everything arrives as text

A file is text, so row["score"] is "92", not 92. Adding two of them concatenates. Convert on the way in, with int or float, before any arithmetic.

import csv

with open("scores.csv", "w") as f:
    f.write("name,score\nAda,92\nGrace,88\n")

with open("scores.csv") as f:
    rows = list(csv.DictReader(f))

print(rows[0]["score"] + rows[1]["score"])            # "9288"
print(int(rows[0]["score"]) + int(rows[1]["score"]))  # 180

Key idea: The exercises below use a supplied scores.csv. Pressing Run puts that file in place for you, and Check swaps in different files to make sure your code reads it rather than reciting it.

Step 4: When to Use It

Any comma-separated file

Spreadsheet exports, logs and downloads. csv handles quoting and line endings that split() gets wrong.

with open(path) as f:
    rows = list(csv.DictReader(f))

Files with a header row

DictReader turns the header into keys, so the rest of the code reads fields by name.

When Not to Use It

Do not split lines on commas yourself, even for a file that looks simple today. The first quoted name with a comma in it shifts every column after it, with no error.
