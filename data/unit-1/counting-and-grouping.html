Counting and Grouping

Overview

A dictionary is how you count things, and how you split a table into groups.

Beginner 20–25 min
← Previous Unit 1 test

What You Will Learn in This Lesson

By the end of this lesson, you will be able to:

  • Count how often each value appears with a dictionary and .get.
  • Use collections.Counter for the same job, and read its most common values.
  • Group rows into lists by a key with setdefault.
  • Summarise each group — the split-apply-combine pattern behind every group-by.

Why This Matters

“How many in each category?” and “what is the average per group?” are the two questions asked of nearly every table. The dictionary pattern in this lesson is exactly what pandas’ groupby does in unit 7: split the rows by a key, apply a summary to each part, combine the answers. Writing it once by hand is what makes group-by stop looking like magic.

Step 1: Counting with a dictionary

The key is the thing being counted; the value is how many times you have seen it.

1

The first sighting problem

counts[s] += 1 raises KeyError the first time s appears, because there is nothing to add to yet. counts.get(s, 0) + 1 treats an unseen key as zero.

subjects = ["maths", "computing", "maths", "art", "maths"]

counts = {}
for s in subjects:
    counts[s] = counts.get(s, 0) + 1
print(counts)
2

Counter does it for you

collections.Counter is a dictionary built for counting. most_common(n) answers “which values are most frequent?” directly.

from collections import Counter

subjects = ["maths", "computing", "maths", "art", "maths"]
counts = Counter(subjects)
print(counts)
print(counts.most_common(1))

Step 2: Grouping is counting with lists

Same shape, except the value is a list you append to instead of a number you add to.

1

Split the rows by a key

groups.setdefault(key, []) returns the list for that key, creating an empty one on the first sighting. Appending to what it returns fills the group.

rows = [("maths", 92), ("computing", 88), ("maths", 79)]

groups = {}
for subject, score in rows:
    groups.setdefault(subject, []).append(score)
print(groups)
2

Apply a summary to each group

Once the scores are split, each group is an ordinary list and every summary from the last lesson works on it.

groups = {"maths": [92, 79], "computing": [88]}

for subject, scores in groups.items():
    print(subject, len(scores), sum(scores) / len(scores))
3

Combine into one answer

A dictionary comprehension collects the per-group results into a single table: one key per group, one summary per key.

rows = [("maths", 92), ("computing", 88), ("maths", 79)]

groups = {}
for subject, score in rows:
    groups.setdefault(subject, []).append(score)

means = {s: sum(v) / len(v) for s, v in groups.items()}
print(means)

Key idea: Split, apply, combine. In unit 7 this whole block becomes df.groupby("subject")["score"].mean(), and the three words are how that line is explained.

Step 3: Reading the result honestly

A per-group summary invites comparison, and comparisons need the group sizes next to them.

1

Report the count with the mean

A group of one student with 95 “beats” a group of forty with 90. Printing the count beside each mean shows which comparison is worth making.

groups = {"maths": [90, 91, 89, 90], "art": [95]}

for subject, scores in sorted(groups.items()):
    print(f"{subject}: mean {sum(scores) / len(scores):.1f} from {len(scores)} scores")

Step 4: When to Use It

How many of each

Categories, answers, subjects. Counter or a dictionary with .get gives the frequency table.

Counter(subjects).most_common(3)

A summary per group

When the question says “per” or “by”: split into lists with setdefault, then summarise each list.

When Not to Use It

Do not compare group averages without their sizes. A group of one can top the table by accident — report the count next to every mean.
