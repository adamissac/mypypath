Building a DataFrame

Overview

A table is a dictionary of columns that share one index.

Intermediate 20–25 min
← Previous Next: Selecting Columns and Rows

What You Will Learn in This Lesson

By the end of this lesson, you will be able to:

  • Build a DataFrame from a dictionary of columns and from a list of records.
  • Read shape, columns, head and info as the first four questions.
  • Explain why every column shares one index.
  • Spot a load that went wrong from its shape alone.

Why This Matters

Every table you meet for the rest of this course is a DataFrame, and almost every confusing result comes from not having looked at it first. The four checks in this lesson take two lines and catch a wrong separator, a missing header and a numeric column read as text.

Step 1: From a dictionary of columns

The keys become column names and the values become the columns. Every column shares the same index, which is what makes a row a row.

1

Columns first

This is the shape pandas thinks in. A DataFrame is not a list of rows that happens to be rectangular; it is a set of columns that happen to line up.

import pandas as pd

df = pd.DataFrame({
    "name": ["Ada", "Grace", "Alan"],
    "score": [92, 88, 79],
})
print(df)
print(df.shape)
2

From records, when that is what you have

A list of dictionaries works too, and it is what an API usually hands you. The union of the keys becomes the columns, and a record missing a key gets NaN.

import pandas as pd

records = [{"name": "Ada", "score": 92}, {"name": "Grace"}]
print(pd.DataFrame(records))
3

One index, shared

Both columns are Series over the same index. Pull one out and the index comes with it — which is why a filtered column still knows which rows it came from.

import pandas as pd

df = pd.DataFrame({"name": ["Ada", "Grace"], "score": [92, 88]})
print(df["score"].index)
print(df.index)

Step 2: The first four things to ask it

shape, columns, head and info answer "what am I holding" before you do anything else. Skipping them is where most confusing results begin.

1

How much, and what of

Shape first, because a number you did not expect here means the rest is not worth reading yet.

import pandas as pd

df = pd.DataFrame({"name": ["Ada"], "score": [92]})
print(df.shape)
print(list(df.columns))
print(df.head())
2

info answers two questions at once

It gives the dtype of every column and how many non-null values each holds, which is the fastest way to see both a text column that should be numeric and a column full of holes.

import pandas as pd

df = pd.DataFrame({"score": ["92", "88"], "n": [1, None]})
df.info()

Key idea: A one-column DataFrame where you expected six is the signature of the wrong separator. The shape told you before any of the numbers did.

Step 3: When to Use It

Several columns about the same rows

A dictionary of equal-length lists, or a list of records, becomes a table with one index.

df = pd.DataFrame({"name": names, "score": scores})

Data from code rather than a file

Test cases, small reference tables, results you computed and want to summarise.

When Not to Use It

Do not build a DataFrame by appending one row at a time in a loop — it copies the table every time. Collect rows in a list first and build once.
